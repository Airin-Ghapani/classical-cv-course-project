# Project provenance and reuse notice

This repository is a cleaned portfolio version of a university computer-vision course project.

## Authorship boundary

The original course material supplied portions of the notebook scaffold, including some of the following:

- data-loading helpers;
- evaluation metrics;
- baseline utilities;
- synthetic-data generators;
- experiment/evaluation harness code.

The student's work includes the core classical methods, original modifications and ablations, experimental use of the scaffold, lightweight learned comparisons, capstone codec, analysis, and written reflections.

The notebook labels the shared course scaffold and the student's implementation sections explicitly so that the repository does not imply authorship of the entire scaffold.

## Licensing

No open-source license is applied to this repository bundle. Course-provided scaffold code may be subject to the course or institution's own terms. Before applying an MIT, Apache, GPL, or other license to the whole repository, confirm that you have permission to relicense any course-provided material.

## Dataset files

BSDS500 source images and annotation files are intentionally not included. Use `scripts/download_bsds_samples.py` to retrieve the official archive from Berkeley and extract the sample IDs used in the notebook. Follow the dataset's official usage and citation guidance.
